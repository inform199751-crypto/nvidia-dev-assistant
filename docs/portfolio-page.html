對內研發助理
實測紀錄

一個給公司內部用的程式碼助理:找 bug、提修正、寫技術文件,也能讀公司文件、看截圖。為了程式碼隱私不接雲端 Claude / GPT,改用 NVIDIA 的模型與 NIM 容器,開發期打 API Catalog,正式環境換成地端,只改一個設定。這一頁記錄我從 10/6 到 10/15 邊做邊用真模型測試的過程,實測與審查一共抓到 61 個問題。

agent 迴圈是自己寫的,沒有用現成的 create_agent,因為 token 檢查、歷史瘦身、模型升級都要插在「每一步送出之前」。工具只能讀、只能在沙箱裡跑測試、只能提 patch 等人確認,不會直接改任何檔案。

長度路由只管放不放得下。另外有一個難度分類器判斷題目難不難,難題改用 DeepSeek。先用影子模式只記錄「本來會選哪個模型」,10/25 用 17 題端到端評測比較(依難度選模型 16/17、只用 Super 12/17)之後才打開。

  10. 42

    設定加引號;讀設定時把 True / False 當成 on / off

安全與隱私 10

  1. 08
    讀檔工具擋不住 .env,金鑰可能被送出去接真實專案前檢查
    封鎖 .env、金鑰、憑證與 .git
  2. 16
    搜尋工具會跟著捷徑連結(symlink / junction)讀到工作區外的檔案程式碼審查 本機重現
    依實際位置檢查,工作區外與機密檔一律略過
  3. 18
    沙箱直接掛載整個工作區,.env 在沙箱裡讀得到審查
    沙箱一律掛排除機密檔的複本,判斷跟讀檔工具同一套
  4. 27
    從 GitHub 加專案時,git clone 會自動用電腦上存的登入,私人 repo 會被抓下來送到外部 API假伺服器 + 假 helper 實測
    clone 時清掉登入輔助程式、關掉提示;同一個實驗兩個 helper 都沒被叫到
  5. 28
    下載的 repo 自帶的規則檔會直接進系統提示,別人寫的內容被當成團隊規則審查
    下載專案的規則改存在 repo 外面,repo 裡那份只當一般檔案
  6. 38
    網頁可以藏給 AI 的指令(例如要它把 .env 傳出去),只靠系統提示不夠保險審查
    網頁和搜尋結果先過安全模型,不安全就整段不交給模型
  7. 43
    「不要把公司程式碼送到試用平台」只寫在文件裡,趕時間把資料夾拖進來就送出去了審查
    設定檔標明哪個後端能放公司資料;試用平台上公司資料夾一律擋(加專案、知識庫、拖進來、以前加過的),其他資料夾第一次要先確認不是公司資料,畫面一直顯示提醒
  8. 46
    MCP 連接器是第三方程式,照預設啟動會繼承環境變數,NVIDIA 金鑰會一起交給它審查
    啟動時拿掉 .env 的變數和像金鑰的;用會印出環境變數的假連接器驗證
  9. 48
    網頁預覽的網址帶著 HSUAN 的 token,沙箱裡的程式讀得到、可以整頁導出去帶走實測時審查
    預覽改用這個網頁專用的鑰匙(token 的 HMAC,反推不回、只能開那一頁)
  10. 57
    終端機照預設會帶著 NVIDIA 金鑰,打 env 就印出來,再一鍵就送給模型審查
    拿掉 .env 的變數和像金鑰的;終端機只有這台電腦能用

為什麼長文本選 Ultra

顯存會不會爆,看的是每個 token 佔多少 KV cache
Qwen2.5-Coder-32B一般 dense 架構
256 KiB / token · 128K 對話約 32 GiB
DeepSeek V3MLA 壓縮注意力
約 69 KiB / token · 約 8.6 GiB
Nemotron 3 Ultra108 層只有 12 層 attention
12 KiB / token · 約 1.5 GiB(1M 約 11 GiB)

參數最少的 Qwen Coder 反而最容易在長對話把顯存吃光;Ultra 是 Mamba 混合架構,大部分層不存 KV cache,這是它能開到 1M 上下文的原因。數字由各模型公開的 config 換算(BF16)。

還沒做的

知道邊界在哪
  • 地端 NIM 沒有實際部署。需要 GPU 伺服器;Ultra 550B 要 8 張 B200 / H200 等級,建議第一階段先用 Super 120B(FP8 約 2 張 H100)。
  • 多人部署只在本機 Docker 測過,還沒在公司 SSO 和 GPU 主機上跑;多台伺服器要設 sticky session。
  • 沒有獨立的工作佇列:整份文件這種 8 分鐘的任務會佔住一個執行名額,同時執行上限要依 GPU 數量調整。
  • 依難度選模型 10/25 打開,但分類器跟出題時標的難度只有 9/15 一致,真實使用的準確度還要看紀錄。
  • PoC 期間不能送公司真實程式碼到 build.nvidia.com:試用條款允許 NVIDIA 收集輸入輸出改進模型。這次測試用的是我自己的專案和虛構的示範文件。
