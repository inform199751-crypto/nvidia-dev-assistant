# 訂單狀態規則

客服、財務、倉庫都照這份走;程式要跟這份一致。

| 現在的狀態 | 動作 | 變成 | 附帶 |
|---|---|---|---|
| pending(待付款) | pay | paid | |
| pending | cancel | cancelled | |
| paid(已付款) | ship | shipped | |
| paid | cancel | cancelled | 全額退款:`refunded_amount` = 訂單金額 |
| shipped(已出貨) | deliver | delivered | 記下送達時間 `delivered_at` |
| delivered(已送達) | return | returned | 只能在送達後 7 × 24 小時內(剛好 7 × 24 小時也可以) |
| returned(已退貨) | refund | refunded | 全額退款:`refunded_amount` = 訂單金額 |

- 表上沒有的組合一律不允許:丟 `InvalidTransition`,訂單的狀態、金額、紀錄都不變。
- 已出貨的訂單不能取消:要等送達後走退貨。
- 每次成功的轉換都在 `history` 記一筆 `(原狀態, 動作, 新狀態, 時間)`。
